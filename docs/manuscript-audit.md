# Manuscript audit handoff

For a manuscript with weak narrative flow, implementation-heavy Methods or diffuse citation use, dispatch a bounded editorial/source audit before another general polish. This uses the existing research roles and state runtime; it does not change installed skills or add a scientific quality classifier.

The coordinator names a scientific editor, using a writer/planner responsibility, to own the reader's path through the whole argument. Literature specialists match consequential assertions to the actual passages, equations and conditions of primary sources. Mechanism specialists separate observed effects, model-based interpretation and untested physical explanations. Section writers revise their assigned passages, and an independent-context reviewer inspects the resulting source, figures and rendered pages. The coordinator closes each return with an interpretation and the next concrete action.

Give each specialist the affected source version, adjacent passages, the precise question, relevant original-source locators, known counterevidence, owned output paths, acceptance rationale and a finite return point. A heading or a bibliography entry does not establish source support. Prefer the closest content-matched papers in the target or related journals; retain necessary seminal or material-data sources regardless of venue. One source may be reused when its actual content supports each use. Neither an arbitrary reference count nor a ban on reuse establishes coverage.

Keep model assumptions, governing variables, essential controls and observation definitions in the article. Place expanded derivations and algorithm details in the appendix, dependency versions and commands in reproduction instructions, and agent execution history in provenance records. This allocation preserves reproducibility without making software execution the scientific subject. Distinguish published/adapted/local equations, physical/numerical/fitted parameters and official journal requirements/observed conventions/editorial choices.

Section openings should make the local scientific purpose and connection apparent where needed, through an observation, definition or unresolved interpretation. Avoid compulsory identical roadmaps. Headings and sentence choices follow the study's argument and actually read journal examples; learning structure does not authorize copying published prose.

Return located defects with source/support scope, a feasible repair, its scientific or reader consequence and recommended disposition. Inspect the repaired source/output before closing a consequential issue. Record scientific and editorial progress separately; pure editorial work does not promote physical evidence. Two attempts without either improvement require reassessment of inputs or method, while a newly located defect justifies a focused continuation.
