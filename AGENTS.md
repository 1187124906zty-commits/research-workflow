# Developing ResearchFlow

This repository implements research governance, not a solver or a claim of scientific truth. Keep the core instructions short and mode details in references. Runtime checks enforce deterministic bookkeeping; domain agents interpret science.

Use bounded subagents for independent implementation/review with disjoint writes. Do not change PaperSpine managed product files, user credentials or unrelated Codex configuration. Preserve real scientific failures and negative results; do not turn them into PASS to finish a demo.

For Python changes, run `python -m unittest discover -s tests -v` and the affected real CLI/example. Skills require frontmatter validation and a realistic independent forward test when materially changed. TOML role charters inherit model/settings; do not hard-code model choices without a user reason. Include actual test scope and limitations in documentation.
