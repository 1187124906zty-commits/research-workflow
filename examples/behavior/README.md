# Forward-test scenarios

`scenarios.json` contains synthetic, explicit research records and realistic user requests. An independent agent should read the governance/simulation skills and these records, choose the next scientifically useful action, return a bounded task and write only what the evidence permits. Do not supply the intended answer or a keyword rubric to that agent.

These cases probe task priority, error-to-effect reasoning, condition reconstruction and research revision. They are not experimental findings or an evaluation of every scientific discipline. The documented observed run and its limitations are in `docs/validation.md`.
