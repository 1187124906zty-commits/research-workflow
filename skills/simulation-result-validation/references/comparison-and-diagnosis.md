# 比较、测量映射与偏差诊断

在比较量不能直接对应、参考资料需加工、误差具有多来源，或偏差需要定位时读本文件。此处负责把已请求结果与依据配对；由请求者决定科学解释和新增研究问题。

## 1. 确立可比性

按工况配对几何/试样、材料参数、荷载或边界条件、初态、环境条件与观测时刻。实验条件不完整时记录缺失字段及影响；不能只因曲线名称相同就认为同工况。理论解记录假设及适用极限，检查仿真是否满足它。

观测定义至少覆盖变量、单位、位置/区域、时间、统计方式。位移、速度、应变等检查坐标系、符号、参考零点；m 与 mm、绝对与相对量、总量与密度分别转换。面平均、体平均、截面通量和点值不能直接互换。归一化说明分母和来源，避免共同归一化掩盖绝对偏差。

以观测算子 `H` 表示测量映射：`y_sim = H(u_sim)`，与 `y_ref` 比较。`H` 可以是采样、区域积分、传感器平均、时间窗统计或已知仪器响应。保存区域、权重、插值规则和加工代码/公式；映射应由测量定义决定，不能为缩小残差任意调整。插值限于参考或结果覆盖区间，外推另标。峰值、到达时刻、频率等特征应有一致的提取定义。

参考数据可以来自表格、补充文件、公开数据、理论公式或图像数字化。记录文件/DOI/页码图表、提取方式及分辨率限制；图像读数不可凭空增加精度。已用于参数识别、模型选择或阈值调节的数据标为校准。留出部分只有在未参与这些决定且对应目标泛化条件时才能作为独立验证。

## 2. 比较产物与误差解释

逐工况保留配对值及有符号残差 `r = y_sim - y_ref`。按用途选绝对误差、RMSE、最大误差或特征差异；接近零的参考量不使用无说明的百分比误差。不同单位/尺度的数据不要混成一个无权重总分。只有需要跨工况汇总时才说明权重与覆盖范围。

`comparison.csv` 的建议列：`case_id, run_id, reference_id, data_role, observable, coordinate_or_region, time, unit, simulated, reference, residual, uncertainty, uncertainty_type, status`。字段可按任务增减；未知值留空并在报告解释，不能写 0。映射和来源较长时用路径/ID 关联，报告给出索引。分布、曲线或空间场宜保留点级数据和适合用途的摘要。

区分实验测量、参数、数值离散、随机抽样及数据提取的不确定度；不把模型偏差藏入宽误差带。给出估计方法、样本数、区间定义和可用前提。仅在有依据时传播或合成不确定度；未知分量写未知。随机模拟说明种子/独立实现及总体统计量，已有合理重复可直接复用；单实现不能自动支持总体可靠性。确定性结果的数值误差不是随机标准差。

比较标准来自指定用途、已提供规范或预先声明的任务判据。数值容差和实验接受阈值分别解释。可描述结果误差大小，但无阈值或不确定度资料时不据“看起来接近”判为用途通过。实验存在时优先用其评价现实用途；理论 benchmark 支持方程实现、极限行为或限定理论用途，不能替代现实实验覆盖。

## 3. 最少必要数值核验

读取运行日志和已有检查，确认结果不是未收敛迭代、中断快照或错误工况。检查对目标量有意义的平衡/守恒、约束与边界实现；例如整体守恒通过并不保证局部峰值准确。

网格、时间步或求解误差的检查围绕可能改变目标判断的因素选择。已有细化结果足够时引用其证据；需要补算时向 runner 指定变化量、目标观测和终止条件。接触/断裂/局部化等结果可检查事件或分支差异，而非强行要求平滑的 Richardson 收敛。缺少足够证据时限制 `NUMERICALLY_CHECKED` 的覆盖，不制造普遍收敛声明。

## 4. 有界诊断与返回

先形成能复现原症状的反馈，例如同一位置的残差、错误峰值时间或质量失衡。排查顺序按证据选择：配对与单位 → 测量映射/加工 → 原运行状态及数值误差 → 资料或模型条件是否可比。每次改动针对一个可证伪原因，修复后重算同一比较；换工况或换指标不能证明原症状消失。

交给 runner 的请求包含 run/case ID、原症状、需修复的数值问题或必要补跑、预期返回路径和判定依据。交给证据负责人的请求包含原件、缺失实验条件/观测定义/数据角色及影响。由请求者协调这些角色；没有可调用角色时保留具名待办，不虚构已发送请求。检查和修复仍不能消除偏差时，报告已排除项、剩余解释及证据缺口，交回上游决定是否研究机制或扩展工况。

范围结论写明参数区间、材料/几何、边界条件、观测量和用途中哪些有直接证据。已执行比较的趋势可以报告，并注明样本与范围；不能把趋势当成因果机制或向未比较区间外推。局部失败影响哪些结论、哪些独立结论仍成立，要明确指出。`EXPERIMENT_COMPARED + FAILED` 与 `NUMERICALLY_CHECKED + INCONCLUSIVE` 都是合法返回。
