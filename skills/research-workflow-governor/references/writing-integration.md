# Writing inside an existing research project

Use this interface when assigning prose or connecting a selected paper workflow. ResearchFlow retains the question, evidence and scientific decisions. The writer returns actual text and consequential evidence questions. Ordinary editing remains a direct task.

## Choose the requested interface

| Requested output | Interface |
|---|---|
| Journal, readership or argument advice | Relevant PaperSpine planning methods; return the planning artifact to the coordinator |
| Assigned prose or manuscript integration | Available `research-writing-skill`, or this package's [writing-craft.md](writing-craft.md) when unavailable |
| A PaperSpine product already selected by the user | Its actual production entry, valid existing task, material bindings and delivery contract |

These are alternatives, not a required pipeline. A selected product keeps its saved choices and synchronization requirements. A file writer does not start a product workflow, repeat intake or create another research coordinator.

## Dispatch and recover

Reuse the existing task packet. Include the paper's central argument, this passage's purpose, adjoining text, protected facts and terms, relevant original evidence locations, owned output path and return condition. A writer using `research-writing-skill` carries its short core standards and one current workflow; examples and detailed resources are opened only for the present writing decision.

For a long paper, assign disjoint writing outputs and track the sections actually read and revised. The coordinator integrates prose, repairs transitions and aligns the abstract, contributions and conclusions. Coverage records preserve comprehensive review without placing all references and research history in each worker's context.

A figure handoff shares the passage's intended judgment, comparison or model relationship, evidence and actual figure. Its return must support the same scientific meaning. Targeted author dialogue uses the integrated passage or figure, and the reply changes the affected manuscript. Workers do not each conduct an interview or infer approval from silence.

The existing coordinator records accepted choices and dispositions once. A connected PaperSpine host retains its product identity and artifacts; cross-reference locations rather than creating duplicate decisions. Writers do not edit shared research state. Missing evidence returns as an affected claim, needed information and feasible route; unaffected prose continues.

## Interpret the return

Read the actual prose and consequential sources. Decide whether the domain problem leads naturally to the method and whether comparisons establish the stated findings. Accept, partly accept or return specific defects with reasons. Editorial acceptance does not promote scientific support, establish identifiability or extend validation beyond tested conditions.

The optional [Scientific Writing Library](https://github.com/1187124906zty-commits/scientific-writing-library/tree/codex/research-writing-coordination-20261010) supplies the general writing standards, three execution workflows and sourced exemplar navigation. Its domain and language tools are optional providers, not new ResearchFlow runtime dependencies. Respect explicitly selected ARS, MAF or other paper workflows through their own contracts; bounded assistance returns to the current owner.

Stop when the assigned writing question has been answered and the manuscript has been read in context. Do not add another complete review simply because another skill is installed.
