# R4：有来源的章节写作方法与熔池案例评价

[当前研究稿 PDF](../manuscript.pdf) · [原位 LaTeX 源](../manuscript.tex) · [完整源码包](../submission-source.zip) · [最终全文审查](review/independent-review.md)

本轮把标题、摘要、引言与科学叙述的具体意见转为可复用的多 agent 写作方法，再用既有 IN625 熔池研究检查其作用。主协调者负责论证和整合；文献/写作专家负责原始指导与研究线；全文评阅者检查真实源码、科学原件和 PDF 页面；另一评阅角色评价新指南在旧稿前向任务中的实际行为。

## 方法依据与分工

[原始写作来源账本](guidance/source-ledger.json)记录 12 份实质阅读的机构/学者页面，来自 MIT/Broad/CEE、Manchester、UNC Chapel Hill、PLOS 和 USC Libraries。引用位置、读取范围、短原文与迁移边界分别保存。Harvard 和 Gopen/Swan 未取得原件，未计入阅读。教学经验、本文编辑判断、已发表样本惯例和期刊正式要求保持不同身份。

[机构指导综合](guidance/institution-guidance.md)、[详细章节指南](guidance/section-guides.md)与[整体工作流程](guidance/synthesis.md)给出诊断、条件式原创示例、责任路由和返回条件。公开的是独立编写的知识整理及原始链接；大学指南全文与期刊全文保留为本地阅读材料。

| 职责 | 实际工作与交接 |
| --- | --- |
| 协调者/科学编辑 | 先确定证据支持的中心认识，安排段落链、细节位置和重要修订，读取返回并给出理由 |
| 标题/摘要写作 | 检查名词主干、实际关系、领域搭配与范围；选择能说明中心发现的比较信息 |
| 引言与文献 | 综合研究建立的认识、可比条件和剩余问题，形成相邻段落间的具体关系 |
| 方法/结果 | 客观描述研究设计、参数角色、观测与比较，正文/附录/复现记录按用途分配 |
| 机制/讨论/结论 | 区分观察、解释和仍存假说，回扣科学问题；缺证据时返回可实施的判别问题 |
| 全文评阅 | 从真实产物定位问题，注明依据、影响、责任角色、最小修复与复查结果 |

MAF 独立重构仓库新增七项项目技能；[运行分发说明](https://github.com/1187124906zty-commits/research-assistant-maf/blob/codex/maf-reconstruction/docs/writing-skills.zh.md)解释显式 `writing.mode/sections`、reviewer 方法继承、后续修订的版本绑定反馈，以及 wheel 资源。原安装技能与数值案例未修改。

## 本稿的实际改变

题目采用关系式表达：**Thermophysical-property effects on melt-pool geometry and cooling histories in IN625 laser processing**。标题的核心名词是 effects，on 指向比较输出，末尾限定材料与过程；[标题判断](argument/title-logic.md)记录其科学承诺和可选形式。

摘要从模型内比较中提炼相反物性响应、后相界共同位移以及空间跨度与材料时间的区别，保留约三分之一的时间变化作为量级提示。它描述本研究增进的解释，没有将既有失配包装成预测性能改善。

引言先建立几何和温度信息的联系与区别，再发展热源/输运、观测、物性覆盖、相变、边界位置与材料时间的研究关系。2024–2026 的已有敏感性、观测一致性与物理可达性研究提供当前评估背景。[论证图](argument/argument-map.md)、[18 项来源追踪](argument/synthesis-trace.json)与[近期补充原件定位](argument/recent-source-trace.json)保留共同认识、具体条件和本研究推导身份。

方法直接陈述公开目标的可得性、B 长度标定和其他比较的角色；图注、讨论和结论按实际对象说明结果。量化分析、公式、五幅图与六个生产解继续沿用既有证据。附录补齐经执行快照核对的传输离散。独立审查修复摘要对照定义、实验材料引用范围及工况场表述；[修复响应](review/review-response.md)和[实际复查](review/repair-verification.md)分别记录。

## 前向应用与真实限制

[MAF 前向案例](https://github.com/1187124906zty-commits/research-assistant-maf/tree/codex/maf-reconstruction/examples/ammt-writing-skills)给新请求旧稿、现有证据和章节技能，未给预期修订答案。指南中已有与本案例相邻的原创示例，因此这是同案例应用，不是未见任务上的迁移实验。初次运行在原件核对后超时；沿用原上下文完成章稿，又显式完成结构化报告和对账。原生请求、协调干预及后续审阅的实际范围均记录。

[独立应用评价](forward-use/coordinator-evaluation.md)发现题目与主线有所改善，但摘要仍重复多组数值，引言末段保留太多方法信息。这促使指南补充全段理解负担检查、事实保持与信息选择的区别，以及继续调研前必须指出其能改变的断言。技能分发使方法可用，文本是否充分改善仍需要实际评阅与修订。没有以本案例证明普遍的自主写作质量或科研效率增益。

第二轮真实 worker 收到定位反馈和更新后的指南后，形成了新的章稿。[实际复查](forward-use/attempt-2-recheck.md)确认摘要和引言末段的核心读者问题已修复，并直接核对所有被比较的物性组合仍偏宽、偏浅。指南和反馈同时参与，无法独立归因。这是经过实际修订与复查的同案例应用，仍不建立未见任务迁移或普遍科研效率收益。

[最终执行摘要](forward-use/execution-summary.json)保存原生状态 **complete、2 个专业循环和 7 个已完成角色请求**。两轮专业返回、评阅与请求者处置已闭合，最后协调规划停止新增可选工作。原硬超时中断、同线程恢复、真实进度答复及一次报告路径纠正保持可追溯；此完成范围限于标题/摘要/引言任务，完整 R4 稿的整合与 19 页视觉审查另行记录。

进度治理也进入运行代码：活动 turn 到达检查点先回答未返回原因、当前候选和后续工作价值；必要的慢推理/原件核查继续，有具体重复工作证据才请求最佳候选供其他角色评阅。真实第二轮已产生询问、`source_work` 回答及继续决定。原 reviewer 的恢复则先得到“已可交付”的诊断再完成返回。活动超时不再自动调用 interrupt；[MAF 实现与边界](https://github.com/1187124906zty-commits/research-assistant-maf/blob/codex/maf-reconstruction/docs/agent-progress.zh.md)区分明确取消和启动故障。

## 交付与证据范围

当前为 19 页阅读稿，使用已有 TeX Live 2026 编译；[源码包重建](delivery/package-rebuild-check.json)检查同一 source/图文件的实际重建与逐页内容对应。内置编辑器保持原文件打开，其编译接口仍返回平台目录错误。R4 未增加 PDE 解或独立热测量。

期刊专属作者指南仍有访问缺口；阅读版尺寸与样本章节习惯没有被称作投稿硬性规则。作者/单位、利益声明与实际人类监督的 AI 使用说明需要负责研究者在投稿前完成。当前稿件仍是可供人工评阅的研究初稿，贡献充分性和物理热历史验证需要进一步科学评价。
