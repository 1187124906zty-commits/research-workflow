## 得到的具体研究定位

最近的 AMMT 前驱研究已明确把高温导热率外推视为需要校准的模型假设，并指出实测束斑条件下一个吸收率参数不足以同时约束三维几何；改进几何后仍限制池内温度预测。Myers 的目标期刊研究进一步展示几何相近的参数组合可有不同温度分布。本稿承认这些成果，将问题收窄到**长度标定后，表外导热率和显热比热函数对后部固相线/液相线位置、间距及所对应材料时间的影响**。

这是一项数值敏感性与诊断研究。没有将已有几何/温度歧义包装成首次发现，也没有给既有热传导算法创造新的品牌缩写。当前标题是 *Melt-pool geometry and solidification time in IN625 laser melting: sensitivity to high-temperature property extrapolation*。

原件审查还限定了研究类比：前驱各向同性模型偏窄偏深，本文偏宽偏浅；前驱导热率端点是 871°C，当前供应商表是 982°C；热像长度和金相宽深属于不同观察群。不能由两个模型都有几何偏差推成共同偏差机制。[来源报告](sources/report.md)、[来源台账](sources/source-ledger.json)和[物性数学核算](sources/property-math-check.json)记录了具体页码、对象与拒绝主张。Lane 的 PMC 原件身份核对为作者稿，避免沿用历史记录中“最终出版 HTML”的过强描述。

## 通用方法怎样改变

现有技能已有章节目的、文献综合、反向提纲和证据边界；本轮没有将所有缺陷归咎于“缺少指南”。[覆盖审计](guidance/coverage-audit.md)分别检查内容缺失、只有链接、实际未采用及接收未核验。[可复用方法](guidance/reusable-methods.md)补充：

- 对象不明确时，先找原始工作、变量、观察人群或模型，再决定术语。比较必须能展开成两个对象、共同量/算子、改变项、保留项和用途。
- 困难段落暂时标出主语、主要动作、已知前提与新信息；检查主语序列及代词的唯一前件。先修复科学关系，再选择连接词。
- 分开检查相邻句的衔接和整段是否支撑同一个控制判断。顺畅的句链可能仍然偏离研究主线。
- 引言重点随实验、数值、理论或混合证据而变；其末段推导目标与回答路线，摘要提炼实际答案。
- 目录及段落反向提纲用于整篇论证审查。章节开头在读者需要局部目的、前提或比较序列理由时设置。

本轮实读九份新网络指导页面，复读或选读四份既存原件，台账分别说明范围。Duke Graduate School Lessons 1–2 为句间方法提供直接依据，Purdue 为反向提纲提供程序出处；Gopen/Swan 原网页及候选镜像未取得，未声称已读。[精确来源与许可](guidance/source-ledger.md)保留短引与定位，全文阅读记录保持私有。大学教学方法、项目科学判断和期刊硬性条款各有不同身份。

| 责任 | 实际产物与作用 |

| 架构/引言专家 | 从具体研究谱系推导引言；[完整目录与反向提纲](architecture/report.md)、[候选](application/introduction.tex)、[与方法结果的互查](application/introduction-handoff.md) |
| 主协调者/科学编辑 | 维护[共同论证](argument-packet.md)，采用候选，在同一正稿中修订标题、摘要、讨论与结论 |
| 指南/全文审阅者 | 先调查指导并审真实新候选，再审整合源码/PDF；[实际前向审查](review/guide-forward-review.md)、[整稿审查](review/independent-review.md) |
| 来源交叉审阅 | 检查未由该专家撰写的论证章节与原件支持；[交叉核对](review/source-cross-check.md) |

方法与结果同责任不要求合并打印章节。两位写作者实际交换并核对了五项引言承诺。方法分成设计、模型/物性、观察量、标定/比较、数值核查五个部分；结果对应拟合后的形状、后部相界及速度—材料时间。新增外推数学定义，物性图标签同步；原五图、五表、已有定量证据和六个生产解保留，无新 PDE 求解。

MAF 改为向显式 `writing` 请求直接交付短对象方法，向协调者/全文请求再交付章节依赖方法，其余参考按需读取。[实际指令选择记录](application/instruction-delivery.json)由当前 `research_assistant.guidance.load_role` 导出，随后被同任务 Codex 专家实际应用。**本轮没有声称新的原生 MAF 模型批次运行**；以前的真实原生批次仍保留在 R4。独立上下文角色审阅披露既有曝光，同模型评阅并非人类或统计独立同行评审。

首次前向审查发现五项具体问题，包括摘要误写单轨迹长度、点态比热与积分焓的比例关系、跨工况固定源因子与固定功率的歧义及未来两类诊断的区别；协调者修复后再交全文检查。[完整目录与逐段反向提纲](review/reverse-outline.md)用于检查整篇研究路线，[修订处置](review/review-response.md)记录实际关闭与保留的范围。
