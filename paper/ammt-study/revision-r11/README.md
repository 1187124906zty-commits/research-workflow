# R11 当前公开交付

R11 是当前英文研究稿的编辑与交付记录。它保留接受的科学范围，不把 ResearchFlow、MAF 或 PaperSpine 的软件执行写成物理结果，也不把本案例中的材料、工况和参数写入通用 MAF skill。

- [可编辑 Word 与格式说明](word/delivery/format-report.md)
- [术语、对象与科学范围](integration/terminology-and-scope.md)
- [实际源码差异](integration/source-diff.md)
- [期刊要求与本稿适配](journal/requirements.md)
- [源码包独立重建检查](delivery/package-rebuild-check.json)
- [协调者审查处置](review/review-response.md)

本稿采用 Methods 与 Results and Discussion 的章节安排，摘要和引言承担问题定位，方法定义观察量和比较条件，结果与讨论把每个定量响应放回相应证据单元。R11 的文字调整没有新增 PDE、实验或物性规律；匹配精化和补证的实际范围、支持/待证/否证边界均保留在交付记录中。

## 文件边界

公开目录只包含当前手稿、必要图件、源码包、复现说明和不含第三方原件的记录。Additive Manufacturing 作者指南原件、参考论文原件、OCR、完整人工评估包和大型中间场文件留在本地人工评估资料包，不随公开仓库分发。Word 转换只改变表示形式；字体、分页、静态编号和其他差异见格式说明。
